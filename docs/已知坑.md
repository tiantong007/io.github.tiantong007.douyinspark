# 已知坑

## 1. LSPosed 相关

| 现象 | 原因 | 处理 |
|---|---|---|
| 装完新包名模块，LSPosed 里是"未启用" | 只在 `staticScope=false` 时发生 | 本项目 `module.prop` 是 `staticScope=true`，**装完自动启用+勾作用域** |
| 模块不注入 | 目标 app 进程是旧的 | 只需重启**抖音**（`am force-stop` + `am start`），不需要重启手机 |
| 手工改 `modules_config.db` 后仍不生效 | lspd 缓存 + 需要 zygote 重新 fork | 改完必须重启设备（这条路不推荐，优先用管理器 UI） |
| `org.lsposed.manager` 打不开 | 管理器不是普通 app，`monkey` 也拉不起 | 从 `/data/adb/modules/zygisk_lsposed/manager.apk` 手动安装 |

## 2. 配置相关

| 现象 | 原因 | 处理 |
|---|---|---|
| 改了 `spark_config.json` 的 body，App 里显示"未写文案" | App 启动时按 snapshots 重建会话列表，会覆盖部分字段 | 改配置必须**先 force-stop App**，改完再打开 |
| 手动发送提示"跳过：XXX（没有文案）" | 该会话不在 `conversations` 数组里（只存在于 snapshots） | 在 App 里勾选并「移入已选目标」，会写入 conversations |
| 卸载重装后配置全丢 | `/data/data` 随卸载删除 | 卸载前 `su -c cp` 出配置，装完推回（owner 必须改成新 uid） |

## 3. 群聊解禁（本项目的改动）

| 风险 | 说明 |
|---|---|
| 群成员都能看到 | 单聊只有对方，群聊是全员可见（例：「XXX(4)」4 个人都看得到） |
| 候选数量暴增 | 35 个快照里含多个群，开总开关后会自动进「已选目标」 |
| 风控 | 多群同模板同时间发，抖音比单聊敏感 |
| 遗留未改 | `AutoSparkBridge.kt:929` 的 `if (isGroup && !in forcedRenew) continue` 还没删，**自动发送仍会跳过群聊** |

建议：先只勾 1 个群试，观察 2~3 天再放开。

## 4. 互动表情相关

| 现象 | 原因 | 处理 |
|---|---|---|
| 发出去是 `[STICKER:续火花]` 文字 | 装的是官方版，或配置 body 被重置 | 确认装的是本项目版本 + body 正确 |
| 发送失败 | `contentObj` 反序列化失败 / sendMessage 不适用于 msgType=5 | 用 frida 查真实发送入口 |
| 表情图不显示 | `url` 签名过期 | 用 frida 重抓 content（见「续火花表情协议」） |

## 5. 构建相关

| 现象 | 原因 | 处理 |
|---|---|---|
| `Failed to find package 'platforms;android-37'` | sdkmanager 仓库里还没有 37 | 已把 compileSdk/buildTools 改成 36 |
| `sourceCompatibility VERSION_21` 编译失败 | 用了 JDK 17 | 必须 JDK 21 |
| `INSTALL_FAILED_UPDATE_INCOMPATIBLE` | 签名变了 | 卸载重装，或开 CorePatch 的 `Bypass digest`（小米别开 `Use previous signatures`，官方警告会开不了机） |
| 移动源码目录失败"正在使用中" | Gradle daemon 占用 | `.\gradlew.bat --stop` 再移动 |

## 6. frida 相关

| 现象 | 原因 | 处理 |
|---|---|---|
| attach 抖音超时 / spawn 卡死 | 抖音检测 `frida-server` 进程名和 27042 端口 | 改名 `fsd` + 监听 8899 + remote device 连接 |
| `frida-ps -U` 里抖音名字乱码 | Windows 控制台编码 | 用 `-H 127.0.0.1:8899` 连，或 `chcp 65001` |
| 重启手机后连不上 | fsd 不是 Magisk 服务，不会自启 | 重新跑 `tools\frida-on.ps1` |
