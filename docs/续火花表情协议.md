# 续火花表情协议

## 结论

抖音「互动表情」里的「续火花」（火焰贴纸）是 **msgType = 5** 的独立消息类型，不是文本表情码。

| 对比项 | 普通表情码 | 互动表情 |
|---|---|---|
| 例子 | `[续火花吧]`（小火人举牌） | 面板里「互动表情」第一格（火焰） |
| 本质 | 文本消息 msgType=7，抖音渲染成图 | 独立消息 msgType=5 + 贴纸 content |
| 能否用 `ctx.result.push()` 发 | ✅ 能 | ❌ 不能（会变成文字） |

## content 结构（实测抓取）

抓法：frida hook `com.bytedance.im.core.model.Message$Builder.build()`，点的同时打印 `getMsgType()` / `getContent()`。

```json
{

  "emoji_type":   "lite_emoji",
  "emoji_from":   "lite",
  "sticker_type": 12,
  "resource_type": 4,
  "width": 100, "height": 100,
  "id": "0", "package_id": 0, "image_type": "png",
  "is_card": false, "updateConversationTime": true,
  "url": {
    "uri": "https://p11-sign.douyinpic.com/obj/im-resource/1687263281313-ts-e7bbade781abe88ab12e706e67?lk3s=...&x-expires=1826161200&x-signature=...",
```

关键点：

- `id = "0"` — 不依赖表情库 id，靠 `sticker_type=12` + `emoji_type=lite_emoji` 区分
- **url 签名有效期到 2027-11-14**，可直接硬编码复用
- content 类名：`com.ss.android.ugc.aweme.im.sdk.chat.model.StickerEmojiContent`

完整样本：`D:\czj\xx\autojs\dy\证据\续火花表情\content_样本.json`

## 发送链路

```
模板脚本 ctx.result.push("[STICKER:续火花]")
        ↓
AutoSparkBridge 发送前判断 StickerCatalog.isStickerMark()
        ↓ 是
StickerCatalog.byName("续火花") → content JSON
        ↓
ImMsgBridge.sendStickerJson()
  1. GsonUtil.INSTANCE.fromJson(json, StickerEmojiContent) → contentObj
  2. builder.conversation(conv) + msgType(5) + content(json) → build()
  3. 回填 contentObj / contentUpdateFrom = "message_builder"
  4. 补 ext（old_client_message_id / im_client_send_msg_time / a:ntp_ready）
  5. IMessageUtils.sendMessage(message, emptyMap, listener)
```

## 标记约定（私有）

```
[STICKER:表情名]
```

- **只有本项目版本认这个标记**；官方 SparkFlame v1.5.7 会把它当普通文本发出去
- 退回官方版前必须把模板 body 改回正常文案
- 扩展新表情：在 `StickerCatalog.CONTENT` 里加一条 `"表情名" to """{...}"""`

## 已踩的坑

- 互动表情**不走** `IMessageUtils.sendMessage` 之外的路径？——实测：点面板时 `Builder.build` 会被调用，但 `sendMessage` 不触发，真实发送入口在混淆类 `X.1T9i.LIZIZ` / `SendMsgServiceLogic` 里。用模块自己构造 message 再调 `sendMessage`（`sendTextJson` 的做法）是可行的，但**尚未在真机验证成功**。
- `uiautomator dump` 的坐标与面板实际渲染可能差 500px（多窗口叠加时），点面板别用 dump 坐标，用截图量。
