> 当前状态：**只做本地 git 提交，不建 GitHub 仓库、不发 release**。等模块精简完再走这套。

## LSPosed 仓库的硬性要求

来源：https://github.com/Xposed-Modules-Repo/.github/blob/main/profile/README.md

1. **仓库名必须等于模块包名** → `io.github.tiantong007.douyinspark`
2. **仓库必须有非空 description**（就是商店里显示的模块名）
3. **必须至少有一个 release**
4. release 必须带 apk 附件，且 **tag 名格式为 `VersionCode-VersionName`** → `11107-v1.5.7-cc`

提交入口：https://modules.lsposed.org/submission

> 官方提醒：只改 release 里的 APK 文件不会触发同步机器人，必须"发布 release"这个动作本身。

## 五步

```
① GitHub 建仓库 io.github.tiantong007.douyinspark
   Description: 抖音续火花cc · 抖音自动续火花（支持互动表情）

② push 源码 + README + LICENSE
   README 必须写「基于 WorldMargin/SparkFlame 修改」（Apache-2.0 要求）

③ 建 Release
   Tag:  11107-v1.5.7-cc
   Asset: release\douyinspark-cc-arm64-v8a.apk

④ 提交 modules.lsposed.org/submission

⑤ 审核通过后，机器人会镜像到
   github.com/Xposed-Modules-Repo/io.github.tiantong007.douyinspark
```

## 发布前检查表

- [ ] README 有上游链接 + Apache-2.0 声明
- [ ] LICENSE 文件在根目录
- [ ] versionCode 已递增（否则用户收不到更新）
- [ ] 用**同一个 keystore** 签名（换签名会导致老用户无法覆盖安装）
- [ ] README 写明「与官方星火燎原签名不同，同时装需先卸载其一」
- [ ] README 写明「需要 LSPosed 2.x（API 101+）」
- [ ] README 写明「`[STICKER:xxx]` 是本版私有标记」

## 版本号规则

```
versionCode 递增（11107 → 11108 …）
versionName 保持 v1.5.7-cc 风格，可加小版本：v1.5.7-cc2
tag         = <versionCode>-<versionName>  → 11108-v1.5.7-cc2
```
