# 构建与签名

## 一键

```powershell
cd D:\czj\xx\douyinspark
.\build.ps1                 # arm64 + armeabi 都签
.\build.ps1 -Arm64Only      # 只签 arm64（快）
```

产物：`release\douyinspark-cc-<abi>.apk`

## 手动分步

```powershell
$env:JAVA_HOME    = "D:\czj\xxrj\jdk21"
$env:ANDROID_HOME = "D:\czj\xxrj\android-sdk"
cd D:\czj\xx\douyinspark\src

# 1. 编译（首次约 4.5 分钟，之后 1~1.5 分钟）
.\gradlew.bat :app:assembleRelease --console=plain --no-daemon

# 2. 对齐
& "D:\czj\xxrj\android-sdk\build-tools\36.0.0\zipalign.exe" -p -f 4 `
   app\build\outputs\apk\release\app-arm64-v8a-release-unsigned.apk ..\tmp\a.apk

# 3. 签名
& "D:\czj\xxrj\android-sdk\build-tools\36.0.0\apksigner.bat" sign `
   --ks ..\keystore\tiantong-release.keystore `
   --ks-pass pass:cc123456 --key-pass pass:cc123456 `
   --out ..\release\douyinspark-cc-arm64-v8a.apk ..\tmp\a.apk

# 4. 校验
& "...\apksigner.bat" verify --print-certs ..\release\douyinspark-cc-arm64-v8a.apk
```

## 环境要求

| 项 | 版本/路径 |
|---|---|
| JDK | **21**（`sourceCompatibility = VERSION_21`，用 17 会编译失败） |
| compileSdk / buildTools | 36 / 36.0.0（上游写的是 37，本机 SDK 没有，已改为 36） |
| Gradle | 9.5.1（wrapper 自动下载） |
| Android SDK | `D:\czj\xxrj\android-sdk`（`src\local.properties` 指向它，不在 git 里） |

## 安装

```powershell
adb -s <serial> install -r -g release\douyinspark-cc-arm64-v8a.apk
```

覆盖安装前提：**签名一致**。换了 keystore 必须先卸载。

## 卸载重装时的配置迁移

```powershell
# 备份
adb shell "su -c 'cp /data/data/io.github.tiantong007.douyinspark/files/spark_config.json /sdcard/cfg.json'"
adb pull /sdcard/cfg.json backup\cfg.json

# 卸载 + 装
adb uninstall io.github.tiantong007.douyinspark
adb install -r -g release\douyinspark-cc-arm64-v8a.apk

# 启动一次让 App 建目录
adb shell "am start -n io.github.tiantong007.douyinspark/com.worldmargin.autospark.app.ui.settings.SparkSettingsActivity"
adb shell "am force-stop io.github.tiantong007.douyinspark"

# 推回配置（uid 用 dumpsys 查）
adb push backup\cfg.json /sdcard/cfg.json
adb shell "su -c 'mkdir -p /data/data/io.github.tiantong007.douyinspark/files; cp /sdcard/cfg.json /data/data/io.github.tiantong007.douyinspark/files/spark_config.json; chown 10276:10276 /data/data/.../spark_config.json; chmod 600 /data/data/.../spark_config.json'"
```

## LSPosed 注册（改包名后）

`module.prop` 里 `staticScope=true`，所以**装完不用手动启用、不用重启手机**——打开 LSPosed 管理器就能看到模块已启用、作用域已勾。只需重启**抖音**让 hook 注入。
